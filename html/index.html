Local device helper

↗OPTIONAL

Run the downloadable helper on a Windows PC or Mac to show that computer's open ports, listening programs and built-in protections here. It only reads; it never changes your settings.

On a phone or tablet? The helper runs on computers only. Use Check this device below instead; no download needed.

Downloads a ZIP with the helper and a connection file just for this browser. Windows: extract it and double-click the EXE. Mac: follow the steps that appear after downloading.

Mac: open Terminal (Applications > Utilities), paste this and press Return:

cd ~/Downloads/Port-a-Potty-Mac-Helper && python3 port_a_potty_helper.py

Or double-click Start Port a Potty Helper.command in the extracted folder. If macOS offers to install Command Line Tools, click Install and run it again.
